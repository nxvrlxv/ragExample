# Кодекс этики

## Кодекс делового поведения

1. Не принимать подарки от поставщиков дороже 3000 ₽.
2. Соблюдать конфиденциальность данных клиентов.
3. Не допускать дискриминации по любому признаку.
4. Сообщать о конфликте интересов HR в течение 3 дней.
5. Бережно относиться к корпоративной ёлке в холле.

Нарушения рассматривает этический комитет в составе HR, юристов и представителя профсоюза.
